Znuny-ContainerHelper
=====================
Provides package event hooks for container deployments. After package install, reinstall, upgrade, or uninstall, marker files are written so the surrounding environment can restart the web server and daemon.

**Prerequisites**

- Znuny 7.5

**Installation**

Install it via the "Znuny OpenSource Add-ons" repository from the package manager or
download the package and upload it via admin interface -> package manager.

**Usage**

See the included documentation.

**Download**

Download the latest version from the [Znuny add-ons](https://addons.znuny.com) repository when available, or use the package file supplied with your distribution.
